# random-meal-generator

## Description

Kitchen Gadgets is a collection of simple tools made to make meal planning easier. 

## Use

If someone in your life could benefit from the tools on Kitchen Gadgets, fork the repository and update with your own recipe collection! 

Feel free to browse the recipe list to inspire your next meal!

## Features in development

- Search by ingredient feature
- Script to add recipe-ingredient sets using a txt file as input

## Contributing

Pull requests will not be accepted at this time.
